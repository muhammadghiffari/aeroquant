AeroQuant: architecture and trading flow

Verified runtime path: market data -> deterministic quant gates -> LLM interpretation -> deterministic risk and execution.

Entry cycle
1. Data
Alpaca stock/options/news APIs
Optional BTC shadow telemetry
2. Quant engine
Momentum, probability lower bound, liquidity, DTE, delta, quote age
3. Candidate whitelist
Exact long call/put contracts only
↓
LLM sub-agents
Trend, volatility, news/earnings
Managers + chief
Synthesize context, choose candidate or WAIT
Fail closed
Invalid JSON, stale data, critical event, or no candidate -> WAIT
↓
Risk gate
Max loss, exposure, buying power, liquidity, DTE, circuit breaker
Execution
alpaca-py, paper-only, idempotent intents, limit order
Monitor + evidence
Fill-based TP/SL, reversal exit, ledger, SQLite, JSON reports, Telegram
